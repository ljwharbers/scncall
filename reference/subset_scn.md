# Subset an scn object by cells and/or bins

Subset an scn object by cells and/or bins

## Usage

``` r
subset_scn(scn, cells = NULL, bins = NULL)
```

## Arguments

- scn:

  scn object

- cells:

  logical/integer/character selector of cells (NULL = all)

- bins:

  logical/integer selector of bins (NULL = all)

## Value

scn
