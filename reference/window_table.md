# Windows table (coordinates per window id)

Windows table (coordinates per window id)

## Usage

``` r
window_table(bins, ids)
```

## Arguments

- bins:

  bins table

- ids:

  window ids from
  [`window_ids()`](https://ljwharbers.github.io/scphasedcn/reference/window_ids.md)

## Value

data.table window, chrom, start, end, n_bins
