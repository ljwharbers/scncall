# Write a simulated data set in the extraction-layer layout

Write a simulated data set in the extraction-layer layout

## Usage

``` r
write_sim_dataset(sim, dir)
```

## Arguments

- sim:

  result of
  [`simulate_scn()`](https://ljwharbers.github.io/scphasedcn/reference/simulate_scn.md)

- dir:

  output directory

## Value

named list of paths
