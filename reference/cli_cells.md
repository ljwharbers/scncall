# Cell subset from a file (one cell per line or a TSV with a `cell` column)

Cell subset from a file (one cell per line or a TSV with a `cell`
column)

## Usage

``` r
cli_cells(path, all)
```

## Arguments

- path:

  file path or NULL

- all:

  all cell names (returned when `path` is NULL)

## Value

character vector
